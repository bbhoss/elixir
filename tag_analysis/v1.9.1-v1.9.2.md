# Changes from v1.9.1 to v1.9.2

## Overview

**Release Date:** October 12, 2019
**Previous Release:** July 18, 2019
**Total Commits:** 13
**Time Span:** 2 months, 24 days

This patch release focused on fixing critical bugs discovered in v1.9.1 after the major v1.9 release that introduced the Releases feature. The changes span bug fixes across the compiler, the new Releases functionality, and platform-specific improvements.

## Summary

Version 1.9.2 is a maintenance release that addressed several important issues in the Releases feature (new in v1.9), along with critical compiler bugs. The release cycle shows a steady stream of bug fixes rather than major new features, which is typical for a patch release following a major feature release. Most commits include fixes for edge cases and platform-specific issues discovered through real-world usage of the new Releases functionality.

The release demonstrates the maturity of the Releases feature after initial v1.9 release, with refinements to handle more complex scenarios like umbrella applications and improvements to Windows compatibility.

## Major Features and Improvements

### Release Version Resolution Enhancement (#9280)
- **Commit:** b43a6a923e
- **Author:** Gary Rennie
- **Impact:** Adds support for `{:from_app, app_name}` syntax in mix.exs release version configuration
- **Use Case:** Umbrella projects can now easily share version numbers across multiple applications by referencing another app's version via `Application.spec(:my_app, :vsn)`
- **Benefit:** Reduces boilerplate and prevents version inconsistency in complex project structures

### Build Reproducibility
- **Commit:** 66ac6a3d8a
- **Author:** Fernando Tapia Rico
- **Significance:** Fixes a bootstrapping issue in the compiler that caused non-deterministic AST generation
- **Technical Details:** During bootstrap, the `defexception` macro wasn't including import metadata for unqualified Kernel calls, causing inconsistent AST when the Kernel was recompiled later. This affected exception definitions like `FunctionClauseError`.
- **Impact:** Ensures reproducible builds across different build environments

## Bug Fixes

### Compiler and Language Issues

1. **Variable Named 'super' Compilation Bug (#9390)**
   - **Commit:** 50caa25d41
   - **Severity:** High
   - **Description:** Fixed a compiler error when using a variable named `super`
   - **Impact:** Users couldn't use `super` as a variable name, which was syntactically valid but incorrectly rejected

2. **Local Capture Macro Expansion Issue (#9245)**
   - **Commit:** 7002554a47
   - **Description:** Ensured the capture operator (`&`) for local functions expands correctly inside macro definitions
   - **Impact:** Fixes edge case where local function captures didn't work properly in macro contexts

3. **Regex Dynamic Recompilation Options Bug (#9343)**
   - **Commit:** a2f14bd007
   - **Severity:** High
   - **Description:** Fixed regex recompilation not respecting options, particularly affecting case-sensitive parsing
   - **Impact:** Fixes parsing issues in `URI.parse/1` when precompiled on different machines
   - **Note:** This was causing URI parsing to appear case-sensitive intermittently

### Release and Mix Issues

1. **Windows Executable Path Quoting (#9242, #9243)**
   - **Commit:** 660a09b3af
   - **Severity:** Medium
   - **Platform:** Windows only
   - **Description:** Fixed executable path handling on Windows when spaces are present
   - **Impact:** Releases with paths containing spaces now work correctly on Windows

2. **Release Install Command Windows Fixes (#9310)**
   - **Commit:** 8ca3876b10
   - **Platform:** Windows only
   - **Description:** Multiple fixes for the `mix release install` command on Windows
   - **Impact:** Windows service installation now works reliably

3. **Cookie Generation Security Issue (#9328)**
   - **Commit:** 92af3fdf0f
   - **Severity:** Medium
   - **Description:** Changed cookie generation from Base64 to Base32 encoding to avoid unsafe characters
   - **Impact:** Prevents potential issues with special characters in generated cookies that could conflict with shell interpretation

4. **Release RPC Tests Stability (#9253)**
   - **Commit:** e60fe36740
   - **Author:** Wouter Klijn
   - **Description:** Fixed release RPC test reliability
   - **Impact:** Improved test stability for release remote procedure calls

### Configuration and Documentation

1. **Manifest Cleanup User Guidance (#9308)**
   - **Commit:** c7e822345b
   - **Description:** When Mix can't automatically clean manifests, it now prompts users to do so manually with clear instructions
   - **Impact:** Better user experience when manifest cleanup is needed

2. **Environment Variables Configuration Organization**
   - **Commit:** c443cdee36
   - **Description:** Reorganized the specification of environment variables in a dedicated configuration block
   - **Impact:** Cleaner release configuration structure

3. **Wildcard Configuration Documentation (#9251)**
   - **Commit:** f5735eb697
   - **Author:** Derrick Zhang
   - **Description:** Updated wildcard example to be equivalent with `Mix.Config` in umbrella projects
   - **Impact:** Clarifies best practices for configuration in umbrella project structures
