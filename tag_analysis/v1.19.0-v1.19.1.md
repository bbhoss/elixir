### Simplify computation of mismatched parts for error messages

**Author:** José Valim <jose.valim@dashbit.co>
**Date:** 2025-10-18 18:49:57 +0200
**Commit:** 83c68cecc15052052b0e2ca2841bba1ae81c53fd

Before we were doing:

    common = intersection(actual, expected)
    uncommon = difference(actual, common)

But the second clause is:

    actual and not (actual and expected)

Which is literally the same as:

    actual and not expected

But much faster as it avoids the large nesting of BDDs.

Closes #14836.

### Fix EEx.compile_string passing invalid options to tokenize (#14835)

**Author:** Daniil Kulchenko <daniil@kulchenko.com>
**Date:** 2025-10-16 14:48:33 -0700
**Commit:** a5c9121a7cc6e3fbca483d4277c24b18940cdb55

EEx.compile_string/2 was passing all options to tokenize/2, but
tokenize/2 only accepts tokenize_opt (:file, :line, :column,
:indentation, :trim). This caused dialyzer to correctly flag calls
with :engine or :parser_options as type errors in Elixir 1.19+.

The fix filters options before passing to tokenize/2, keeping only
the valid tokenize_opt keys, while still passing the full options
list to EEx.Compiler.compile/3 which needs :engine, :parser_options,
and custom engine options.

Fixes #14834
