## Summary

This maintenance release focuses on improved tracing capabilities, OTP 28 compatibility refinements, build system improvements, and various quality-of-life enhancements. Notable additions include trace events for definition callbacks and super calls, listener control in Mix commands, and better error messages for edge cases.

### Key Themes
1. **Enhanced Tracing** - New trace events for callbacks and super calls
2. **OTP 28 Refinements** - ExUnit compatibility and per-release Hex/Rebar installation
3. **Build System** - Listener control and module verification improvements
4. **IEx Enhancements** - New process_info helper
5. **Error Messages** - Better diagnostics for reference escaping

## Major Features and Improvements

### Tracing Enhancements

- **Definition Callback Tracing**: Trace on definition callbacks (closes #14427), enabling debugging of macro definition hooks
- **Load Function Tracing**: Trace on load functions (see #14427), providing visibility into module loading
- **Super Call Tracing**: Emit trace events for super calls (closes #14395), allowing tracking of callback chain invocations

These improvements significantly enhance debugging capabilities for complex metaprogramming scenarios.

### Mix and Build System

- **Listener Control**: Added `--no-listeners` to `mix compile` and `mix run`, giving developers explicit control over compilation listeners
- **Module Verification**: Write modules before verification so modules can be found during verification, fixing ordering issues
- **BEAM Location**: Compute beam location early, improving compilation reliability
- **Git Checkout**: Ensure git checkout works with untracked files (#14428), fixing dependency management edge cases

### OTP 28 Compatibility

- **ExUnit Suite**: Fixed ExUnit suite on Erlang/OTP 28, ensuring tests run correctly on the new OTP version
- **Per-OTP Installation**: Install Hex and Rebar per OTP release (#14509), preventing conflicts when using multiple OTP versions

### IEx Improvements

- **process_info/1**: Added `IEx.Helpers.process_info/1` (#14418), providing convenient process inspection without leaving IEx

### Error Messages

- **Reference Escaping**: Raise nice error message when escaping maps/structs with references (closes #14497), improving error clarity for a confusing edge case

### HTTP Client

- **Retry Logic**: Retry mix httpc with disabled middlebox_comp_mode (#14357), improving reliability when downloading dependencies behind certain proxies

### Documentation

- **Debugging Page**: Fixed typo in debugging documentation (#14502)
- **CI Updates**: Updated continuous integration configuration

## Impact Assessment

This release brings several important improvements:

**Tracing Enhancements**: The new trace events for definition callbacks, load functions, and super calls significantly improve debugging capabilities for library authors and advanced developers working with metaprogramming. These additions make it easier to understand and debug complex macro behaviors.

**OTP 28 Compatibility**: Continued refinement of OTP 28 support ensures smooth transition when users upgrade. The per-OTP Hex/Rebar installation prevents version conflicts when working with multiple OTP versions.

**Build System Control**: The `--no-listeners` flag gives developers explicit control over compilation listeners, useful for scenarios where listener overhead isn't desired (e.g., CI environments, scripted builds).

**IEx Improvements**: The new `process_info/1` helper makes process inspection more convenient during interactive development.

**Dependency Management**: The git checkout and HTTP retry fixes improve reliability when managing dependencies, particularly in corporate environments with proxies or complex git workflows.

**Error Messages**: The reference escaping error improvement helps developers quickly understand and fix a confusing edge case.

**Upgrade Recommendation:** Recommended for all v1.18 users, especially those:
- Working with advanced metaprogramming and needing better tracing
- Using or planning to use Erlang/OTP 28
- Managing multiple OTP versions
- Working behind corporate proxies
- Needing fine-grained control over compilation listeners
- Using IEx for process inspection

The 76-day gap between releases indicates excellent stability in the v1.18 line, with this release adding valuable debugging capabilities and refining OTP 28 support.
