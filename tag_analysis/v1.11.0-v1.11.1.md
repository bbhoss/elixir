# Changes from v1.11.0 to v1.11.1

## Release Overview

**Release Date Range:** October 6, 2020 – October 16, 2020
**Total Commits:** 14 (13 content commits + 1 release commit)
**Release Type:** Patch/Bug fix release

This patch release focused on stability improvements, bug fixes across the compiler and logging systems, and addressing false positive warnings that were causing confusion for developers.

---

## Summary of Changes

The v1.11.1 release is primarily a **stability and quality assurance patch** that addresses critical bugs and improves the robustness of core components. The release maintains backward compatibility while fixing issues in the Logger system, compilation warnings, and type checking.

### Key Themes:
1. **Logger System Stability** - Fixed a critical deadlock issue in sync mode
2. **Warning Accuracy** - Reduced false positive warnings in various contexts
3. **Type Checking Improvements** - Fixed error handling in the type system
4. **Compilation Robustness** - Improved handling of edge cases in comprehensions and app filtering
5. **IPv6 Support Enhancement** - Added fallback to inet6 in Mix's HTTP client

---

## Major Features & Improvements

### Stream Mode Enhancement
- **Commit:** `ff95a59ec` - Add :append to stream_mode, closes #10421
- **Impact:** New `:append` mode added to `File.stream/3` and related functions
- **Significance:** Provides developers with an additional stream mode option for file operations, complementing existing modes like `:read` and `:write`

### IPv6 Fallback Support
- **Commit:** `4081590742` - Add inet6 fallback to Mix usage of httpc, closes #10423
- **Impact:** Mix now falls back to IPv6 (inet6) when downloading dependencies if IPv4 is unavailable
- **Significance:** Improves network compatibility in IPv6-only environments and dual-stack configurations

### Documentation Improvements
- **Commit:** `ccdefd904f` - Improves the docs of config/runtime.exs and Config.config_env/0 (#10414)
- **Impact:** Enhanced documentation for runtime configuration handling
- **Significance:** Better guidance for developers using runtime configuration patterns

## Bug Fixes

### Critical Issues

#### Logger Deadlock Fix
- **Commit:** `b4605374b5` - Do not deadlock Logger if handler crashes on sync mode, closes #10420
- **Files Changed:** `lib/logger/lib/logger/handler.ex`, `lib/logger/test/logger_test.exs`
- **Problem:** Logger could deadlock when a handler crashed while operating in synchronous mode
- **Solution:** Improved error handling and timeout logic to prevent deadlock scenarios
- **Severity:** Critical - prevented applications from hanging due to logger crashes

### Compiler & Type System Fixes

#### Module.Types.Expr Error Handling
- **Commit:** `b2059031a6` - Fix returning errors in Module.Types.Expr.of_expr (#10410)
- **Impact:** Fixed error propagation in type expression evaluation
- **Significance:** Ensures type errors are properly reported to developers rather than causing crashes

#### Comprehension :reduce Handling
- **Commit:** `ffbcc004ec` - Do not crash when :reduce is set to nil in comprehensions, closes #10411
- **Problem:** Compiler would crash if `:reduce` was explicitly set to `nil` in comprehension expressions
- **Solution:** Added defensive check for nil values in reduce expressions
- **Impact:** Improves compiler robustness with edge case inputs

#### App Filtering with Targets
- **Commit:** `081f99cd3` - Consider targets when filtering apps, closes #10405
- **Problem:** Application filtering logic wasn't correctly accounting for compilation targets
- **Solution:** Updated app filtering to properly consider target specifications
- **Impact:** Fixes issues with multi-target builds and umbrella projects

### Warning System Fixes

#### GenServer.child_spec/1 False Positive
- **Commit:** `e3479831ba` - Do not show warning when `super` is in `GenServer.child_spec/1` (#10418)
- **Problem:** Compiler was incorrectly warning about using `super` in `GenServer.child_spec/1`, which is a default implementation, not a callback
- **Solution:** Excluded `child_spec/1` from the deprecated `super` warning
- **Impact:** Eliminates confusing false positive warning for valid code patterns
- **Related Issue:** #10415

#### App Requirement Warning Message
- **Commit:** `36ec08e0c8` - Fix warning message in app requirement (#10417)
- **Problem:** Warning message had a syntax error (missing closing bracket in example code)
- **Before:** `[xref: [exclude: :crypto]` (missing closing bracket)
- **After:** `[xref: [exclude: :crypto]]` (corrected syntax)
- **Impact:** Provides correct, copy-paste-ready examples to developers

#### Clause Traversal Warnings
- **Commit:** `ed2829d8ea` - Keep warnings when traversing clauses
- **Problem:** Warnings were being lost during clause traversal in certain compilation phases
- **Solution:** Preserved warning context during clause analysis
- **Impact:** Ensures developers see all relevant warnings

### Infrastructure & Reliability Fixes

#### Tracer Robustness
- **Commit:** `ae0ac9b3c9` - Ignore tracers if lexical tracker is dead or explicitly nil
- **Problem:** Code tracing could fail if the lexical tracker was unavailable
- **Solution:** Added defensive checks to skip tracing in these scenarios
- **Impact:** Improves stability during debugging and code analysis

#### Logger Test Suite Stability
- **Commit:** `e0d61c7875` - Fix order dependent tests in logger suite
- **Problem:** Logger tests had implicit ordering dependencies that caused random failures
- **Solution:** Made tests properly isolated and independent
- **Impact:** Improves CI/CD reliability and test reproducibility

## Breaking Changes

**None.** This is a pure patch release with no breaking changes to the public API or language semantics.

## Notable Commits Worth Highlighting

### 1. Logger Deadlock Prevention (b4605374b5)
This is the most critical fix in the release. The Logger system is foundational to many Elixir applications, and a deadlock bug could cause entire applications to hang. This fix adds proper timeout and error handling to prevent hangs when logging handlers crash.

### 2. Stream Mode Addition (ff95a59ec)
Though a small change (1 line), this addition completes the stream mode functionality by providing the `:append` option, which is essential for append-only file operations - a common pattern in production systems.

### 3. False Positive Warning Removal (e3479831ba)
This fix demonstrates the team's commitment to improving developer experience by removing incorrect warnings that were causing confusion, especially for developers properly using `GenServer.child_spec/1`.

### 4. IPv6 Fallback (4081590742)
Important for modern infrastructure where IPv6 is increasingly prevalent. The fallback ensures Mix can resolve dependencies in IPv6-only environments.
