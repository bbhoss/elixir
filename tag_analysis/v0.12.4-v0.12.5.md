# Changes from v0.12.4 to v0.12.5

## Date Range and Statistics

- **v0.12.4 Release**: February 12, 2014
- **v0.12.5 Release**: March 9, 2014
- **Duration**: 25 days
- **Total Commits**: 25 commits

This was a relatively focused release with a mix of bug fixes, deprecations in preparation for v0.13, and important compiler/build improvements.

---

## Summary of Key Changes

The v0.12.4 to v0.12.5 release represents a maintenance and preparation release. The primary focus was on:

1. **Preparing for v0.13**: Multiple deprecations were introduced for functionality that would change or be removed in the next major version
2. **Bug fixes**: Several important bugs in core libraries (String, HashDict) were fixed
3. **Build system improvements**: Enhanced recompilation logic and Mix utility functions
4. **Deprecating GenFSM**: A significant decision to deprecate the GenFSM module in favor of better abstractions

The release strikes a balance between maintaining stability and moving the language forward through strategic deprecations.

---

## Major Features & Improvements

### Automatic Recompilation on Outdated Elixir Version
- **Commit**: `969d48ccaf` (Feb 12, 2014)
- **Impact**: The compiler now automatically triggers recompilation when the Elixir version becomes outdated, preventing subtle issues from running code compiled with different versions
- **Significance**: Improves reliability in development workflows where Elixir versions change

### Mix.Utils Function Improvements
- **Commits**: `207c626a6c`, `7308d81729`, `177a900be3` (Feb 14, 2014)
- **Changes**:
  - `Mix.Utils.camelize` now properly handles empty strings
  - `Mix.Utils.underscore` now accepts dots (`.`) in strings and handles edge cases
- **Impact**: More robust utility functions reduce bugs in build and project configuration handling

### Application Restart on System.argv Changes
- **Commit**: `cb81c6b5c7` (Feb 21, 2014)
- **Impact**: When System.argv changes during `mix run`, the application is now properly restarted, ensuring system arguments are correctly passed to the running application
- **Significance**: Fixes a subtle but important issue in how CLI arguments are handled

### String Library Guards
- **Commit**: `11c4c279` (Feb 12, 2014)
- **Changes**: Added guards to `lstrip` and `rstrip` functions
- **Impact**: Better compile-time safety and clarity about what types these functions accept

### Code Generation Optimization
- **Commit**: `28367d9073` (Mar 6, 2014)
- **Changes**: After clauses in generated code are now only included when required
- **Impact**: Reduces generated code bloat and makes the compiled output cleaner

## Bug Fixes

### String.slice Error
- **Commit**: `9ebe851b38` (Feb 21, 2014)
- **Issue**: `String.slice("string", 0..-2)` was incorrectly returning `nil` instead of the proper substring
- **Example Before**:
  ```elixir
  String.slice("string", 0..-2)  # returned nil (wrong!)
  ```
- **Example After**:
  ```elixir
  String.slice("string", 0..-2)  # returns "strin" (correct)
  ```
- **Impact**: Critical fix for string slicing with negative indices

### HashDict.equal? Subset Comparison
- **Commit**: `2121ce1875` (Feb 23, 2014)
- **Issue**: `HashDict.equal?/2` was not correctly handling comparisons when one dictionary was a subset of another
- **Impact**: Fixes inconsistent behavior in dictionary equality checks

### Rebar Dependencies Handling
- **Commit**: `4637b5797` (Feb 15, 2014)
- **Issue**: Raw rebar dependencies were not being handled correctly
- **Impact**: Improves compatibility with Erlang dependencies managed through rebar

### Waiting List Cleanup
- **Commit**: `4ab8225cf` (Mar 9, 2014)
- **Issue**: Spurious entries were accumulating in the waiting list, potentially causing memory leaks or unexpected behavior
- **Impact**: Improves system stability and resource management

## Deprecations

### GenFSM Module Deprecation
- **Commit**: `455eb4c4ac` (Mar 8, 2014)
- **Reasoning**: The commit message explicitly states:
  > "We plan to provide better abstractions around GenServer and GenEvent in upcoming releases but we won't do so for GenFSM. There are other interesting approaches out there, like `plain_fsm`, which are easier to understand and use than OTP's FSM."
- **Timeline**: Users should migrate to alternative approaches like `plain_fsm` or build FSM logic on top of GenServer
- **Impact**: Significant API change; developers should begin planning migration strategies

### Type Check Functions (is_regex/1, is_range/1)
- **Commit**: `2cc4fd2eb5` (Feb 19, 2014)
- **Functions**: `is_regex/1` and `is_range/1` are deprecated
- **Replacement**: These type-checking functions will be removed in v0.13
- **Impact**: Users relying on these functions need to find alternative approaches

### Broader v0.13 Deprecations
- **Commit**: `126a5a61df` (Mar 5, 2014)
- **Scope**: Multiple pieces of functionality are marked for removal or change in v0.13
- **Message**: "Deprecate more functionality to be changed or removed in v0.13"
- **Impact**: Signals broader API evolution in progress; developers should review deprecation warnings

### Sigil Warning
- **Commit**: `f2c914926d` (Feb 12, 2014)
- **Change**: Using `%` as sigils now emits warnings
- **Reason**: Preparing for changes in sigil syntax
- **Migration**: Users should update to the new sigil syntax

---

## Removed Features

### MIX_GIT_FORCE_HTTPS Environment Variable
- **Commit**: `aa87d44cba` (Mar 8, 2014)
- **Reason**: "This used to be useful in case the git port was blocked" - less relevant as network situations evolve
- **Impact**: Projects relying on this environment variable for git operations need alternative solutions
- **Note**: This is a breaking change for users who depended on this option

---

## Breaking Changes

1. **MIX_GIT_FORCE_HTTPS Removal** (Minor)
   - Removed support for the `MIX_GIT_FORCE_HTTPS` environment option
   - Users needing to force HTTPS for git operations need to find alternative solutions

2. **GenFSM Deprecation** (Major)
   - While not removed in this release, GenFSM is now officially deprecated
   - This sets the stage for removal in v0.13
   - Users should plan migration to alternative FSM implementations

3. **is_regex/1 and is_range/1 Deprecation** (Minor)
   - These functions are deprecated with removal planned for v0.13
   - Affects code that relies on runtime type checking

## Notable Commits Worth Highlighting

### 1. String.slice Fix (`9ebe851b38`)
One of the most important bug fixes in this release. String slicing is a fundamental operation, and the incorrect handling of negative indices could cause subtle bugs in production code.

### 2. GenFSM Deprecation (`455eb4c4ac`)
A significant architectural decision that signals the direction of the language. This deprecation reflects a philosophy shift toward building abstractions on top of GenServer rather than maintaining a separate FSM module.

### 3. Automatic Recompilation (`969d48ccaf`)
An often-overlooked but crucial improvement that prevents a class of hard-to-debug problems where code compiled with one Elixir version is run with another.

### 4. Mix.Utils Robustness (`207c626a6c`, `7308d81729`, `177a900be3`)
Three related commits improving the robustness of Mix utility functions. While individually small, together they reduce friction in the build system.

### 5. Deprecation Batch (`126a5a61df`, `2cc4fd2eb5`, `455eb4c4ac`)
Multiple deprecations in a short time frame indicate intentional planning for v0.13's major changes. Users who keep their code warning-free will be well-prepared for the next major release.

- **Early Phase (Feb 12-15)**: Initial development work including compiler improvements, sigil warnings, and string library enhancements
- **Mid Phase (Feb 19-23)**: Bug fixes and deprecations, focusing on core library stability
- **Late Phase (Mar 3-9)**: Final integration including documentation updates, additional deprecations, and bug cleanup before release

## Upgrade Recommendations

For users upgrading from v0.12.4 to v0.12.5:

1. **Review deprecation warnings**: Compile your code and pay attention to deprecation warnings, especially for GenFSM, is_regex/1, and is_range/1
2. **Test string operations**: If your code uses `String.slice` with negative indices, retest to ensure it now produces expected results
3. **Check environment variables**: If using MIX_GIT_FORCE_HTTPS, find an alternative approach
4. **Plan for v0.13**: Use this release as an opportunity to prepare your codebase for v0.13, where many deprecated features will be removed

This is generally a safe upgrade with no critical breaking changes, though the GenFSM deprecation should be taken seriously by affected applications.
