# Changes from v0.6.0 to v0.7.0

## Overview

**Date Range:** October 8, 2012 to October 20, 2012 (12 days)
**Commit Count:** 352 commits
**Release Type:** Minor version bump

This was a significant development period for Elixir with substantial improvements to the standard library, language features, and tooling. The version focused heavily on API refinement and standardization rather than completely new features.

## Key Themes and Summary

The v0.6.0 to v0.7.0 release represents a major consolidation and stabilization of Elixir's core libraries and APIs. The primary focus areas were:

1. **String Processing Overhaul** - The Binary module was renamed to String with comprehensive UTF-8 handling improvements
2. **Data Structure API Normalization** - Keywords were made unordered and improved, Record API expanded
3. **Protocol System Enhancement** - Protocols now powered by behaviors with support for multiple implementations
4. **Mix Build System Evolution** - Added environment support, escriptize feature, and nested dependency handling
5. **Language Grammar Refinements** - New bitstring syntax, improved quote/unquote support, better atom handling
6. **Deprecation Warnings** - Beginning of systematic API cleanup and removal of legacy features

## Major Features and Improvements

### String Module and UTF-8 Support

- **Binary module renamed to String**: The module responsible for handling UTF-8 binaries was renamed from Binary to String for clarity. Keep Binary.Inspect for backwards compatibility.
- **New String API functions**:
  - `String.first/1` - Get first character
  - `String.last/1` - Get last character
  - `String.length/1` - Get string length
  - `String.at/2` - Access character at position
  - `String.codepoints/1` - Get codepoints (refactored to use String.codepoint as main entry point)
- **String manipulation functions**:
  - `String.upcase/1` and `String.downcase/1` - Case conversion
  - `String.lstrip/1` and `String.rstrip/1` - Whitespace trimming (made rstrip tail recursive)
  - `String.duplicate/2` - Repeat string N times
  - `String.replace/3` and `String.replace/4` - Replace substrings with multiple options

### Keyword Module Improvements

- **Keywords are no longer sorted** (breaking change): Keyword lists now maintain insertion order instead of being automatically sorted. This was a significant change affecting testing and behavior.
- **Added `Keyword.equal?/2`**: New function to compare keywords regardless of ordering
- **Performance improvements**:
  - `Keyword.merge/2` was fixed for consistency
  - `Keyword.delete/2` was optimized for speed
- **Inspect support**: Keywords can now be properly inspected with quoted keys when necessary

### Binary/Bitstring Enhancements

- **New binary inspection**: `Binary.part/2` - Extract part of binary at offset
- **`Binary.split/3` with multiple options**:
  - Global option to match all occurrences
  - Regex support for pattern matching
  - Parts option to limit number of splits
- **Binary literal syntax improvements**: Support for `bytes`, `bits`, `utf8`, `utf16`, and `utf32` type specifiers in bitstring syntax
- **Binary inspection optimization**: Optimized `Binary.Inspect.Utils.escape` for better performance
- **Binary conversion**: Added `binary_to_integer/1` and `binary_to_float/1` functions as counterparts to `integer_to_binary/1` and `float_to_binary/1`
- **Float inspection**: Better inspect output for floats
- **New bitstring syntax**: Implemented new bitstring literal syntax (closes #421), making zero-based indexing consistent

### Protocol System Enhancements

- **Protocols powered by behaviors**: Major architectural change making protocols backed by behaviors behind the scenes, enabling better integration with Erlang
- **Multiple implementation support**: Added support for defining multiple protocol implementations in one go (e.g., `defimpl SomeProtocol, for: [Atom, Number, List]`)
- **Protocol optimization**: Optimized protocols when there are no fallbacks for better performance
- **Protocol dispatch**: Fixed false negatives in protocol dispatch (closes #503)

### Record Improvements

- **`record.update/2`**: New function to update records in-place
- **Record.defmacros**: Macro-based record definition with:
  - `get/2` macro implementation for accessing fields
  - `to_list/1` macro - Convert record to list
  - `to_keywords/1` macro - Convert record to keyword list
- **`Record.__index__/1`**: New function to get field indices
- **Access protocol**: Support for nested access on records and better integration with access protocol

### Range Support

- **Decreasing ranges**: Added support for ranges that count downward (e.g., `10..1`)
- **Range handling**: Fixed various edge cases with range operations

### Mix Build System

- **Environment support**: Mix now supports multiple environments (test, dev, prod) via MIX_ENV variable
  - `mix test` automatically sets environment to test
  - `mix deps` runs on prod by default
  - Environment configuration can be overridden explicitly
- **Escriptize feature**: Added escript support allowing Elixir projects to be built as standalone scripts
  - By default embeds Elixir in escripts
  - Allows mix to be called as an escript
  - Fine-grained control of included apps
- **Nested dependencies**: Mix now supports nested dependencies with proper order resolution
- **Dependency management**: `mix deps.unlock` no longer complains about unavailable deps
- **File compilation options**: Added `-f` support and file-based compilation with `compile_exts`
- **Task improvements**: Better exit codes (now exits with status 1 on failures)

### IEx (Interactive Elixir)

- **Helper renaming**:
  - `d` helper renamed to `h` (help)
  - `h` helper renamed to `v/0` (last value)
- **Application separation**: IEx broken into its own application
- **Output limiting**: Elixir now limits output in IEx to 50 items
- **TTY support**: Better check for actual TTY support before invoking it
- **Remote node support**: Display "rem" indicator when connected to remote node
- **Terminal integration**: Brings behavior from Erlang's shell to IEx
- **after_spawn callbacks**: Added support for after_spawn callbacks
- **ExUnit after_spawn**: ExUnit now supports after_spawn callbacks

### Macro and Quote Improvements

- **`Macro.term?/1` renamed to `Macro.safe_term/1`**: Renamed to better express the intent
- **Support for unary operators**: Support unary plus and minus in safe_term
- **Quote improvements**:
  - Line in quote can now be an expression
  - Support for `unquote_splicing` on root
  - Support for `unquote_splicing` with pipes
  - Better handling of temporary variables in quote/unquote
- **Macro expansion**: Improved macro expansion including attribute expansion
- **Match inside quotes**: Proper handling of `^` inside quotes with correct hygiene

### Parser and Language Enhancements

- **Bitstring syntax**: Complete implementation of new bitstring syntax for better clarity
- **Atom handling**:
  - Tokenizer can limit atoms to existing atoms only
  - Remove conversion to atom from parser for safety
  - Solve `a::b` ambiguity in parsing
  - If `:B` is allowed, `B:` should be too (consistency)
- **Optional commas**: Added optional comma in lists, tuples, bit strings and keywords (closes #479)
- **Pipe operator**: Can now start at new line (closes #450)
- **Partial application**:
  - Allowed on literals
  - Fixed for lists with many elements and tail
- **Module access**: Improved access protocol with nil support

### Enumerable Module Improvements

- **`List.zip/2` deprecated**: Deprecated in favor of `Enum.zip/2`
- **New Enum functions**:
  - `Enum.reverse/1` - Reverse enumerable
  - `Enum.count/1` - Count elements
  - `Enum.split/2` - Split at position (now supports negative numbers)
  - `Enum.split_while/2` - Split while condition is true (renamed from split_with)
- **Function enumeration**: Support for Enum operations on functions with `Enum.OrdIterator`
- **Access protocol**: Defined and improved throughout

### Dict API Consistency

- **Dict API normalization**: Solved inconsistencies in Dict API
- **Dict binary**: Added Dict binary that converts keys to binaries on insertion
- **Performance**: Simplified Dict implementation and improved various transforms
- **Access protocol**: Dict now properly supports access protocol

## Bug Fixes

### Critical Fixes

- **List.zip and List.unzip infinite loop**: Fixed hanging when called with empty list
- **Protocol dispatch**: Avoided false negatives in protocol dispatch
- **File operations**: File.cp family now preserves file mode permissions
- **IEx alias expansion**: Fixed bug where partial aliases couldn't be expanded in IEx
- **Record extensions**: Fixed offset calculation for record extensions

### Documentation and Compatibility Fixes

- **Code loading**: Code.require_file and Code.load_file now expect full file names
- **Code file unloading**: Allow files to be unloaded
- **Module info**: Ensure Kernel.__info__(:functions|:macros) returns complete set
- **Regex improvements**:
  - Add named groups support in Regex
  - Provide `Regex.captures/1` instead of `Regex.match/1`
  - Return option added to Regex.run and Regex.scan
  - Regex.split supports 'parts' option
- **Error messages**: Better error messages for environment-related issues and invalid options to import/alias/require
- **Macro.to_binary**: Fixed crash when receiving a list

### Performance Optimizations

- **Binary escaping**: Optimized `Binary.Inspect.Utils.escape`
- **Protocol optimization**: Optimized protocols when there are no fallbacks
- **Keyword operations**: Sped up `Keyword.delete`

## Breaking Changes

### Significant Breaking Changes

1. **Keywords are no longer sorted**: This is the most significant breaking change. Code relying on keywords being in a specific order will need to be updated. The new `Keyword.equal?/2` function should be used for keyword comparison.

2. **Binary module renamed to String**: All code using the Binary module should be updated to use String instead. Some Binary module functions remain for backwards compatibility.

3. **Erlang. syntax deprecated**: The `Erlang.Module` syntax is deprecated in favor of simply using atoms (`:module` or `Module`), with warnings issued.

4. **Module.read_attribute and Module.add_attribute deprecated**: These functions are deprecated. Users should use the new attribute handling API.

5. **List.zip/2 deprecated**: This function is deprecated in favor of `Enum.zip/2`.

6. **Macro.term? renamed**: Renamed to `Macro.safe_term/1` for clarity.

7. **Code.require_file and Code.load_file API change**: Now require the full file name as argument instead of partial names.

8. **IEx helper renaming**: The `d` helper is now `h` (help) and the `h` helper is now `v/0`. Code or scripts using these helpers will break.

### API Changes

- `defmodule` behavior change: Now returns module name, binary and the result (previously only returned result and binary)
- `Inspect` options: Now accepts limit and raw as options
- Setup/teardown callbacks: Now pass context in callbacks
- GenServer behavior: Now defines init callback
- Calendar module functions: Some unused calendar functions removed with warnings removed
