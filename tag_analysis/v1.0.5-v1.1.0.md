# Changes from v1.0.5 to v1.1.0

## Overview

**Date Range:** July 26, 2014 to September 25, 2015 (13 months)
**Total Commits:** 1,573
**Release Date:** September 25, 2015

This release represents a significant evolution of Elixir, introducing new data structures, expanding core library APIs, improving tooling, and preparing the language for better performance and future growth. The release bridges support between Erlang 17 and Erlang 18, with v1.2 planned to be Erlang 18 only.

---

## Key Themes and Strategic Shifts

### 1. **Core Data Structures Expansion**
This release adds substantial functionality to core collections and introduces a new data structure (`MapSet`). The most active module by commits is `Kernel.ex` (66 commits), followed by `Enum.ex` (52 commits), reflecting significant work on language fundamentals and enumerable operations.

### 2. **Deprecation and API Refinement**
A major deprecation wave affects the `Access` protocol, marking a shift toward performance-conscious API design. The release also introduces soft deprecations for `Behaviour` and legacy syntax forms, signaling the future direction of the language.

### 3. **Mix Ecosystem Maturation**
Mix receives substantial improvements including better error messages, performance optimizations, new profiling capabilities, and security features (public key management for Hex/Rebar dependencies).

### 4. **Testing Infrastructure Improvements**
ExUnit gains skip functionality, log capturing, and better error reporting, making test development more productive.

## Major Features and Improvements

### Enumeration and Collection APIs

**New Enum functions:**
- `Enum.random/1` - Get a random element
- `Enum.take_random/2` - Retrieve random elements
- `Enum.min_max/1` and `Enum.min_max_by/2` - Find both minimum and maximum in one pass
- `Enum.reverse_slice/3` - Reverse a slice of a collection
- `Enum.reduce_while/3` - Reduce with early termination capability
- `Enum.dedup/1` and `Enum.dedup_by/2` - Remove consecutive duplicates
- `Enum.uniq/2` deprecated in favor of `Enum.uniq_by/2` (more explicit naming)

**Dict module enhancements:**
- `Dict.get_and_update/3` - Atomic get-and-update operation (replaces Access protocol use case)
- `Dict.get_lazy/3`, `Dict.pop_lazy/3`, `Dict.put_new_lazy/3` - Lazy evaluation variants

**Stream module additions:**
- `Stream.dedup/1` and `Stream.dedup_by/2` - Lazy deduplication
- `Stream.transform/4` - Four-argument variant for more flexible transformations

**MapSet introduction:**
A new data structure that implements the Set API using maps underneath. Designed for holding dozens of items in Erlang 17, with future versions expected to scale MapSet to millions of entries with superior performance to HashSet.

### Performance Optimizations

- Enum functions now inline common map operations for better performance
- Mix recompilation logic optimized to only recompile compile-time dependencies, significantly speeding up recompilation in Elixir projects
- Compiler cache reliability improved
- Range operations restricted to integers, fixing performance bugs where values were incorrectly included in ranges

### File and I/O Improvements

- **File.lstat/1** and **File.lstat/2** - Symlink-aware file stat operations
- **File.rename/2** - Unix-like `mv` command support
- **File.touch/2** and **File.stat/2** now use universal times instead of local times (monotonically increasing)
- StringIO.flush/1 added for flushing StringIO output

### String and Text Processing

- **String.jaro_distance/2** - Calculate Jaro distance between strings (used by Mix for "Did you mean?" suggestions)
- **String.splitter/3** - Lazy string splitting
- **Unicode support** - `\uXXXX` and `\u{X*}` syntax for Unicode codepoints in strings and char lists
- **EEx trim option** - Automatically trim whitespace around EEx tags for cleaner output

### Process and Task Management

- **Process.hibernate/3** - Reduce memory footprint by hibernating processes
- **Process.info/2** - Accept list of specs instead of single spec
- **Task.yield/2** and **Task.shutdown/2** - Better task lifecycle management
- **IEx.pry** - Support for remote debugging with `--remsh`

### Inspection and Safety

- **Inspect.safe** - New `:safe` option making inspect safe by default (failures wrapped rather than propagated)
- Better error handling when inspecting malformed data structures

### URI and Network

- Default ports for "ws" (WebSocket) and "wss" (Secure WebSocket) schemas
- **URI.to_string/1** - Convert URI struct back to string representation

### Integer and Tuple Operations

- **Integer.digits/2** - Convert integer to list of digits with specified base
- **Integer.undigits/2** - Reverse operation
- **Tuple.append/2** - Append element to tuple

### Module and Code Analysis

- Improved name inference for function signatures in documentation metadata
- Better parameter name generation for function signatures
- `Code.get_docs/2` now stores documentation line in metadata

## Bug Fixes and Stability Improvements

### Critical Fixes

1. **Regex operations:**
   - `Regex.split/2` fixed for empty strings with trim enabled
   - `Regex.replace/4` no longer discards escape characters
   - Regex escape character handling improved

2. **Stream operations:**
   - `Stream.flat_map/2` and `Stream.transform/3` fixed to not consume unnecessary items when suspending

3. **ExUnit:**
   - Fixed bug where inspecting malformed data structures could crash the test runner
   - Proper line number reporting for doctest failures
   - Skipped tests now correctly counted in totals
   - Fixed semantics issue with `assert nil = expr()` pattern

4. **Kernel compilation:**
   - Raise on undefined atom/alias syntax `:foo.Bar`
   - Improved error messages for non-writable target directories
   - Support for capture of non-symbolic operators (`&and/2`, `&not/1`)
   - Heredoc terminal detection improvements
   - Don't warn on missing imports if nothing was imported

5. **Protocol handling:**
   - Derived protocols now guaranteed to go through `Any` instead of `Map`
   - Range type restricted to integers, fixing false positives in range inclusion

6. **Code generation:**
   - `:delegate_locals_to` option replaced by imports (previous version had stacktrace issues)
   - `Macro.to_string/1` properly converts captures

7. **Logger:**
   - Logger metadata properly included in `Logger.log/3`
   - PID and ref printing support in Logger metadata
   - Application metadata automatically included in logs when compiled via Mix

### Mix Tooling Fixes

- HTTPS used instead of Git protocol for GitHub dependencies (security)
- Protocol consolidation properly triggered in umbrella apps
- `--exclude` in `mix test` correctly concatenates with test helper excludes
- Wildcard imports don't raise if nothing matches
- Build embedding (`build_embedded: true`) now requires explicit compilation

## Breaking Changes and Deprecations

### Major Deprecations (with warnings in future releases)

1. **Access Protocol Deprecation**
   - Implementing the `Access` protocol is deprecated due to performance bottlenecks
   - The `opts[key]` syntax itself is NOT deprecated, only protocol dispatch
   - Replacement: Use `Dict.get_and_update/3` for similar semantics
   - Reason: Code server bottleneck in development mode; frequent calls in concurrent systems caused performance issues

2. **Behaviour Module Deprecation**
   - Use `@callback` instead of `defcallback`
   - Use `@macrocallback` instead of `defmacrocallback`
   - More idiomatic and aligned with Elixir's attribute-based approach

### Soft Deprecations (no warnings, documentation updated)

1. **Enum.uniq/2** → `Enum.uniq_by/2` (more explicit about the operation)
2. **`\x` escape sequences** → `\uXXXX` and `\u{X*}` (correct Unicode support)
3. **Regex ungreedy `r` option** → `U` option (standard across languages)

### Hard Deprecations (compile-time errors)

1. **`as: true | false` in alias/require** - This undocumented behavior is now an error
2. **`?\xHEX` syntax** → `0xHEX` - Simpler and more idiomatic

### Behavior Changes

- **`var.Alias` syntax** - Now raises if it doesn't expand to atom at compile time (previously warned)
- **Underscore variables** - Now warned when used (not just when unused)
- **Expression side effects** - Warnings when module attributes, variables, strings, numbers have no effect
- **Arity bounds** - Enforce 0..255 range (raised if violated)

## Notable Implementation Details

### Erlang Compatibility

- Support for both Erlang 17 and Erlang 18
- Added compatibility with OTP 18 typespec changes
- Note: Erlang 17.1 has wildcard regression affecting Rebar - users advised to update to 17.3+
- This is the last release supporting Erlang 17; v1.2 will require Erlang 18+

### Build System Changes

- No longer require `:crypto` and `:syntax_tools` as dependencies
  - Users needing encrypted debug info should manually add `:crypto`
  - `:syntax_tools` no longer used in Elixir
- Rebar dependencies can now be compiled with Mix
- Rebar dependencies can be specified via `:path`
- Support for rebar3 style Git refs in rebar.config
- New config directory handling - subdirectories considered in `config/` for `Mix.Project.config_files/0`

### Mix Security and Reliability

- New `mix local.public_keys` task for safely managing Hex and Rebar installation
- Archive install checksum verification via `--sha512` option
- Version checking immediately after archive installation with user feedback

### Code Organization

- 320+ commits with conventional message format (Fix/Add/Remove/Deprecate/Improve)
- ~289 commits specifically touching major modules
- Primary files modified: `Kernel.ex` (66), `Enum.ex` (52), `String.ex` (49)

## Testing and Documentation Infrastructure

- ExUnit now supports test skipping with `@tag :skip` or `@tag skip: "reason"`
- Built-in log capturing functionality added to ExUnit
- Timeout configuration for entire test suite via `:timeout`
- Module doc filtering for doctest execution
- Configurable `assert_receive_timeout` and `refute_receive_timeout`
- Tests without implementation (missing `do` block) automatically fail and are tagged `:not_implemented`
- Default stacktrace depth increased to 20 (configurable)
- Code of Conduct added to repository

### Mix Profiling

- New `mix profile.fprof` task for code profiling
- Better Mix error messages and warnings overall

## Summary: The Road to v1.1.0

This release represents Elixir's transition from early adoption phase to production maturity. The introduction of `MapSet`, the expansion of `Enum` and `Dict` APIs, the deprecation of the `Access` protocol, and the improvements to Mix and ExUnit collectively demonstrate a commitment to:

1. **Performance** - Optimizing critical paths, restricting types where needed, caching compilation
2. **Ergonomics** - Adding convenience functions while cleaning up legacy APIs
3. **Reliability** - Improving error messages, adding safety features, strengthening testing infrastructure
4. **Future-proofing** - Preparing for Erlang 18, removing dependencies, supporting new Unicode standards

The 13-month development cycle produced a cohesive release that addressed community feedback while maintaining backward compatibility for non-deprecated features. For users, the upgrade path is straightforward, with clear migration paths for deprecated features and soft deprecations clearly documented.
