# Changes from v1.5.1 to v1.5.2

## Overview

**Release Date:** August 1, 2017 (v1.5.1) → September 29, 2017 (v1.5.2)
**Duration:** ~2 months
**Total Commits:** 24

This release focused on bug fixes and quality improvements across the Elixir ecosystem, with particular attention to DateTime handling, pattern matching, error messages, and tooling stability.

## Summary of Key Changes

v1.5.2 is primarily a maintenance and bugfix release that addressed critical issues discovered since v1.5.1. The release includes fixes for DateTime calculations, compiler improvements for pattern matching and default arguments, better error messages and diagnostics, and improvements to Mix task handling. No major new features were introduced, but the changes maintain backward compatibility while improving overall system reliability and user experience.

## Major Bug Fixes

### DateTime and Calendar Handling
- **Fix negative microsecond result from DateTime.from_unix/2** (commit 941ce758ed)
  - Resolved an issue where DateTime.from_unix/2 could return negative microsecond values
  - Calendar.ISO now properly enforces date limits to prevent invalid calculations
  - Improved error messaging when NaiveDateTime is incorrectly passed to DateTime.to_iso8601/2
  - These fixes address precision and correctness issues in datetime arithmetic, critical for financial and time-sensitive applications

### Pattern Matching and Compiler Fixes
- **Fix @impl attribute for default arguments** (commit 759457ecfa)
  - `Module.compile_impl/6` was ignoring default attributes when compiling implementation declarations
  - Now properly checks the count of default attributes and adds an impl declaration for each one
  - Resolves issues with protocol implementations that use default arguments

- **Do not traverse clauses table to retrieve defaults** (commit 2021fed11a)
  - Performance and correctness improvement in how default argument values are retrieved
  - Avoids unnecessary table traversals during function clause compilation

- **Do not crash for unknown var inside binary pattern in match** (commit 37321cd529)
  - Fixed compiler crash when unknown variables appear in binary patterns
  - Improves error handling and prevents abrupt failures during code analysis

### Supervision and OTP Integration
- **Raise better child_spec error if module is not defined** (commit 407d2e1835)
  - Provides more descriptive error messages when Supervisor encounters undefined modules
  - Helps developers quickly diagnose configuration issues in supervision trees

- **Use the name of a registry as its child spec id** (commit 94e5c72793)
  - Fixed Registry child spec to use the registry name as its ID
  - Ensures proper identification and management of multiple registry instances within supervision trees

### Mix and Tooling Improvements
- **Fix local.hex --if-missing** (commit bfa894a15f)
  - Corrected the --if-missing flag behavior in the local.hex task
  - Ensures Hex is installed conditionally as intended

- **Properly convert from list to string in git commands** (commit 0494629c4c)
  - Fixed Git integration in Mix to properly convert command arguments from lists to strings
  - Prevents issues with Git-based dependencies and version control operations

- **Fix mix_exs option in Mix.Tasks.Run** (commit be6e54de16)
  - Corrected handling of the --mix-exs flag in mix run tasks
  - Ensures the mixed environment flag is properly respected during task execution

- **Remove --if-missing when calling archive** (commit 8023b5e0c6)
  - Fixed archive installation logic by removing inappropriate --if-missing flag
  - Prevents incorrect handling of archive updates

### IEx and Developer Tools
- **Do not crash IEx on :init.stop** (commit c99e1cdc9b)
  - Fixed IEx crash when receiving :init.stop signal
  - Improves stability of the interactive shell

- **Ensure nested evaluator entries exit** (commit e1f10a9386)
  - Fixed issue where nested evaluator entries weren't properly exiting
  - Ensures resource cleanup in nested evaluation contexts

- **Do not trigger additional error reports on failures when loading tests** (commit 5b25761d4c)
  - Prevents duplicate error reporting when test loading fails
  - Reduces noise and makes error output clearer for developers

- **Translate built-in Elixir apps sources** (commit d90c7bbb79)
  - IEx introspection now properly translates source information for built-in Elixir applications
  - Improves developer experience when inspecting standard library code

## Error Messages and Diagnostics

- **Improve error message on oversized atom** (commit d1efe7c012)
  - Enhanced tokenizer error messages when atoms exceed size limits
  - Helps developers quickly identify and fix atom-related errors

- **Warn if unary operators are followed by new lines** (commit 6fd203ba7b)
  - Added warning when unary operators are followed by newlines
  - Prevents subtle parsing ambiguities and code formatting issues

- **Properly advertise the --no-mix-exs flag** (commit 0a677fe403)
  - Fixed documentation and help text for the --no-mix-exs flag
  - Ensures developers are aware of this option's availability

## Breaking Changes

**None identified.** v1.5.2 maintains full backward compatibility with v1.5.1. All changes are bugfixes and improvements that do not alter the public API or expected behavior beyond fixing incorrect implementations.
