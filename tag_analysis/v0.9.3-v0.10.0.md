# Changes from v0.9.3 to v0.10.0

## Overview
- **Release Date Range**: June 23, 2013 to July 15, 2013
- **Total Commits**: 340 commits
- **Duration**: ~22 days

This minor version bump represents a significant period of development with major feature additions, API refinements, performance improvements, and breaking changes that shaped the Elixir language during its early evolution.

---

## Summary of Key Themes

The v0.10.0 release represents a pivotal update to Elixir with several major focus areas:

1. **Introduction of the Streams API** - A completely new abstraction for handling lazy, composable sequences
2. **Complete Inspection System Overhaul** - Renamed and refactored the inspection/printing system with pretty-printing capabilities
3. **Record System Refinements** - Breaking changes to record syntax and macro behavior
4. **Build System Modernization** - Improved Makefile with better variable handling and cross-platform support
5. **Performance Optimizations** - Memory and efficiency improvements across core data structures
6. **Improved Error Handling** - Better error messages and error categorization
7. **API Deprecations** - Clear deprecation path for older APIs

---

## Major Features & Improvements

### 1. Streams API (NEW)

The introduction of **Streams** is one of the most significant additions in v0.10.0. This provides a powerful abstraction for lazy evaluation and composable operations on sequences:

- **Core Stream Functions Added**:
  - `Stream.seq/2` - Generate potentially infinite streams of values
  - `Stream.iterate/2` - Generate stream by repeatedly applying a function
  - `Stream.repeatedly/1` - Generate stream by repeatedly calling a function
  - `Stream.cycle/1` - Create a stream that cycles through a collection
  - `Stream.with_index/1` - Attach index to each element
  - `Stream.take/2`, `Stream.drop/2` - Lazy slicing operations
  - `Stream.reject/2` - Lazy filtering (complement of `Stream.filter`)
  - `Stream.take_while/2`, `Stream.drop_while/2` - Conditional slicing

- **Enum Enhancement**: `Enum.with_index/1` added to complement Stream API

- **File API Changes**: `File.*iterator!` functions deprecated in favor of `File.*lines_stream!` to align with Stream naming

- **IO Stream Support**: `IO.stream` and unified `read/readline` API provide consistent access to I/O as streams

### 2. Inspection and Pretty-Printing System Refactor

A major refactor renamed and restructured the entire inspection/printing pipeline:

- **Module Renames**:
  - `Binary.Inspect` → `Inspect` (moved to main namespace)
  - `Wadler` → `Inspect.Algebra` (now sub-module of Inspect)

- **Pretty-Printing Support**:
  - Integrated Wadler/Lindig pretty-printing algorithm for formatted output
  - `Inspect.Opts` record introduced for passing inspection options
  - Pretty printing disabled by default for backward compatibility

- **Keyword List Inspection**: Keywords now inspected as list of tuples with `raw: true` to show actual structure

- **Improved Formatting**: Pretty printer enhanced to print grouped elements on the same line even if they don't fit fully

### 3. Record System Evolution

Several significant changes to how records work:

- **New Record.__record__(:index) Syntax**:
  - Replaces `__index__` mechanism with more consistent `__record__(:index)` approach
  - Issue #1414 resolution provides better meta-information about records
  - Updated System and Mix modules to use new syntax

- **defrecordp/3 Enhancements**:
  - `defrecordp/3` now allows custom record tags (Issue #1339)
  - First element must now be the record name (breaking change from previous behavior where it was the current module)
  - Custom tag allows nesting aliases under parent module
  - Private records no longer automatically nest arguments

- **Record Improvements**:
  - Record rewriter now keeps tags after `setelement`
  - `defrecordp` can import records that depend on other records
  - Records can now import themselves
  - Better error messages and optimization

### 4. Quote and Meta-Programming Improvements

- **quote Syntax Changes**:
  - `quote binding:` deprecated in favor of `quote bind_quoted:` (more accurate naming)
  - New `Macro.t` type documents valid quoted expression types
  - Invalid quoted expressions now raise proper exceptions with clear error messages

- **Alias Quoting**: Can now quote aliases with calls

### 5. Set/HashSet Performance and API Improvements

Significant optimization work on the Set data structure:

- **Performance Enhancements**:
  - `HashSet` now uses trie-based storage for better scaling
  - Memory-efficient node expansion and contraction
  - Optimized `member?` and `intersection` operations
  - `set_filter` support for tries

- **API Additions**:
  - `Set` behavior interface introduced to abstract from `HashSet` implementation
  - `Set.disjoint?`, `Set.subset?`, `Set.equal?` for set comparisons
  - Better integration with Enumerable functions

### 6. Mix Build System Improvements

- **Dependency Management**:
  - `Mix.Version` now used for consistent dependency version handling (Issue #1376)
  - Rebar dependency improvements - all deps of a rebar dep now handled by rebar
  - Validation of Elixir version in projects (Issue #1310)
  - Error when Dict/Set doesn't support the target operation

- **Dependency Override Policy**: Now requires `override: true` option explicitly to override a dependency

- **Archive Support**:
  - `mix archive` supports version specification
  - `-o` flag for output directory control
  - First directory of archive must match archive name (Erlang requirement)

- **Manifest and Compilation**:
  - Simplified manifest API
  - Files deleted from manifest instead of just removing from loadpath
  - Better stale file handling optimization
  - Fresh variable dictionary for eval callbacks

### 7. ExUnit Testing Framework Enhancements

- **Debug/Trace Support**:
  - New `--debug` flag for mix test (renamed from internal `--trace`)
  - ExUnit now supports `:debug` option for detailed test output
  - Works for both mix-run tests and internal test suite

- **Output Formatting**:
  - Refactored and improved ExUnit formatters
  - Removed unnecessary overhead from runner
  - Messages now guaranteed in correct order
  - Removed "test" prefix before each test name for cleaner output

- **Exit Message Handling**: IEx now shows exit messages from test failures

### 8. Error Message and Error Handling Improvements

- **Error Categorization**:
  - `SyntaxError` reserved for actual syntax errors
  - `CompileError` for runtime compilation constraints
  - Better distinction between syntax vs. semantic errors

- **Specific Error Messages**:
  - Improved error messages for typespecs (Issue #1401)
  - Better messages for in-erlang macros
  - Clearer invalid quoted expression errors
  - Improved doctest error messages (Issue #1318)

- **Grammar Tightening**: Ambiguous parentheses-free calls now raise syntax errors with clear indication of the problem

### 9. IEx (Interactive Elixir) Improvements

- **Autocompletion**: Now supports identifiers that include numbers

- **Options System**:
  - Refactored `IEx.Options` to support better composition
  - Raises errors on invalid option keys

- **Windows Support**:
  - Fixed tests on Windows
  - Disabled coloring by default on Windows (Issue #1329)
  - Simplified `runcmd` implementation
  - Fixed `elixir.bat` to accommodate paths with spaces

- **Documentation**: Improved docs for IEx module and helpers

### 10. Performance Optimizations

- **HashDict Optimization**: Pairs now stored in cons cells, reducing storage per key by approximately 50%

- **Inspect Implementation**: Optimized for better performance

- **String Operations**: Using standard library functions for better efficiency

## Deprecations

### 1. **quote binding: → quote bind_quoted:**
   - The `binding:` keyword in quote expressions is deprecated
   - Use `bind_quoted:` instead for more accurate semantics
   - Commit: `84a0985a39`

### 2. **Kernel.float/1 Deprecation**
   - Float conversion function deprecated
   - Use explicit conversion methods instead
   - Commit: `2fee17e709`

### 3. **mix run EXPR → mix run -e EXPR**
   - Running code directly as argument (mix run EXPR) deprecated
   - Use explicit `-e` flag: `mix run -e EXPR`
   - More consistent with other command-line tools
   - Commit: `40653e433b`

### 4. **File.*iterator! → File.*lines_stream!**
   - File iterator functions deprecated
   - Use new `File.*lines_stream!` functions returning Streams
   - Aligns naming with new Streams API
   - Commit: `cf98f9b975`

### 5. **__index__ → __record__(:index)**
   - Old record index mechanism deprecated
   - Use `__record__(:index)` for better consistency
   - Updated throughout System and Mix modules
   - Commits: `73b9ac7449`, `82da86afcb`, `c1a7c039fe`

## Breaking Changes

### 1. **defrecordp/3 Signature Change (BREAKING)**
   - **Previous**: `defrecordp module_name, fields`
   - **New**: `defrecordp record_name, fields, options`
   - First argument is now the record name, not the module name
   - This is a significant breaking change for anyone using `defrecordp`
   - Commit: `c20ee8f7e9`

### 2. **Comprehension Guard Behavior (BREAKING)**
   - Comprehensions can no longer behave like guards
   - This prevents confusing semantic situations
   - Commit: `c0b007af9a`

### 3. **Quote binding: Syntax (BREAKING)**
   - `quote binding: var` syntax no longer works
   - Must use `quote bind_quoted: var` instead
   - More semantically correct

### 4. **Inspect API Changes (BREAKING)**
   - `Binary.Inspect` module renamed to `Inspect`
   - `Wadler` module renamed to `Inspect.Algebra`
   - Projects depending on old module names must update imports

### 5. **ExUnit trace/debug Rename**
   - ExUnit option renamed from `debug` to `trace` internally
   - CLI renamed to `--debug` for clarity
   - Minor compatibility concern for programmatic users

### 6. **URI Lookup Removal (BREAKING)**
   - URI lookup mechanism removed
   - Use application environment instead
   - Commit: `26eafd1a4c`

## Migration Path for Users

For users upgrading from v0.9.3 to v0.10.0, the key migration items are:

1. **Update record macros**: Any `defrecordp` calls need adjustment for new argument order
2. **Update imports**: Change `Binary.Inspect` to `Inspect` and `Wadler` to `Inspect.Algebra`
3. **Update quote syntax**: Replace `quote binding:` with `quote bind_quoted:`
4. **Update file operations**: Move from `File.*iterator!` to `File.*lines_stream!`
5. **Update mix commands**: Change `mix run EXPR` to `mix run -e EXPR`
6. **Remove float/1 calls**: Migrate to explicit conversion methods
7. **Add Elixir version**: Declare compatible Elixir version in mix.exs
