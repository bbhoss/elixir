# Elixir v1.15.5 to v1.15.6 Analysis

## Version Information
- **Previous Version:** v1.15.5
- **Current Version:** v1.15.6
- **Release Date:** September 20, 2023
- **Date Range:** August 30, 2023 to September 20, 2023
- **Total Commits:** 12

## Summary

This maintenance release focuses on formatter enhancements, compiler improvements, and Windows platform support. The release addresses several critical issues in the formatter, improves application loading for umbrella projects, and enhances the Windows installer experience. Notable improvements include better plugin handling in the formatter and more robust error handling.

### Key Themes
1. **Formatter Enhancements** - Multiple improvements to formatter behavior and plugin loading
2. **Windows Support** - Significant improvements to Windows installer and PATH handling
3. **Compiler Optimization** - Better trace handling and inlining behavior
4. **Error Messaging** - Improved error messages across multiple modules
5. **Application Loading** - Optimized application loading for umbrella projects

## Major Features and Improvements

### Formatter Improvements
- **Plugin Loading**: Plugins are now loaded during `formatter_for_file` calls (closes #12930), ensuring formatters work correctly with plugin-based formatting rules.
- **Invalid Block Handling**: Fixed an issue where invalid blocks given to the formatter would cause infinite loops (closes #12922), improving robustness.
- **Bitstring Modifiers**: Fixed formatter handling of `:*` in bitstring modifiers (#12923), ensuring correct formatting of binary pattern matching.

### Windows Platform Support
- **Installer Enhancement**: Improved the Windows installer (#12945), making installation more reliable and user-friendly.
- **PATH Handling**: Fixed PATH handling in Windows installer (#12900), ensuring Elixir commands are properly available after installation.

### Compiler Enhancements
- **Trace Before Inline**: Functions are now traced before they are inlined (closes #12925), ensuring debugging and tracing work correctly even for inlined functions.

### Application Loading Optimization
- **Convergence Optimization**: Applications are no longer always loaded during convergence (closes #12682), improving compilation performance in large projects.
- **Umbrella Support**: Added loading of extra applications for umbrella projects, ensuring all dependencies are properly available in multi-app projects.

## Bug Fixes

### Formatter Fixes
- **Invalid Block Loop**: Prevented infinite loops when invalid blocks are given to the formatter (closes #12922).
- **Bitstring Formatting**: Corrected formatting of `:*` in bitstring modifiers (#12923).
- **Plugin Loading**: Ensured plugins are loaded when needed for file formatting (closes #12930).

### EEx and Tokenizer
- **Warning Display**: Fixed proper printing of warnings from tokenizer in EEx (closes #12926), ensuring developers see important warnings during template compilation.

### Error Messaging
- **Access Module**: Improved error message in the Access module, making it clearer when access operations fail.
- **Mix Format Dependencies**: Enhanced error message when mix format encounters missing dependencies, including environment information for better debugging.

### Windows-Specific Fixes
- **PATH Configuration**: Fixed PATH handling in Windows installer (#12900).

## Breaking Changes

No breaking changes were introduced in this release.

## Impact Assessment

This release is particularly important for Windows users due to the installer improvements. The formatter fixes address critical issues that could cause hangs or incorrect formatting, making this a recommended upgrade for all users. The application loading optimizations will be especially beneficial for large umbrella projects, potentially reducing compilation times significantly. The trace-before-inline fix ensures that debugging tools continue to work correctly even with compiler optimizations enabled.
