### Add metadata support to ExUnit

**Author:** José Valim <jose.valim@plataformatec.com.br>
**Date:** 2013-02-17 18:20:06 -0700
**Commit:** 8f57b4c9afee1946885e6731b6dcfe2440c69b56

Defining setup/teardown/test explicitly is now deprecated.
They should now be defined via their respective macros:

    def setup do
      ...
    end

Now becomes:

    setup do
      ...
    end

When defined using the new format, setup callbacks can
return metadata:

    setup do
      [do_this: :do_that]
    end

And now the test macro can access this metadata:

    test "check metadata", data do
      assert data[:do_this] == :do_that
    end
