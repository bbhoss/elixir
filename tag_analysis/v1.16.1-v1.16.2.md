### Escape pinned values when computing diff (#13354)

**Author:** Philip Munksgaard <philip@munksgaard.me>
**Date:** 2024-02-17 12:51:07 +0100
**Commit:** ff309747b7682d56895a2cf1e13e4f3ed669d5d7

Take these two tests:

```elixir
  test "correctly colored" do
    assert [{:foo}] = [{:bar}]
  end

  test "incorrectly colored" do
    val = [{:foo}]
    assert ^val = [{:bar}]
  end
```

That's because when diffing a pin, we were not converting the underlying
diff context from match to ===.

This fixes #13348
