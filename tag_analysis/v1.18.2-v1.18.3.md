# Elixir v1.18.2 to v1.18.3 Analysis

## Version Information
- **Previous Version:** v1.18.2
- **Current Version:** v1.18.3
- **Release Date:** March 6, 2025
- **Date Range:** January 24, 2025 to March 6, 2025
- **Total Commits:** 19

## Summary

This maintenance release brings important fixes and adds support for Erlang/OTP 28. Key improvements include JSON encoding fixes, protocol consolidation improvements, autocomplete stability, Stream fixes, and various documentation and type system enhancements. The release demonstrates continued refinement of v1.18 features while preparing for the next OTP version.

### Key Themes
1. **OTP 28 Support** - Full compatibility with upcoming Erlang/OTP 28
2. **JSON Improvements** - Fixed key encoding edge cases
3. **Autocomplete Stability** - Fixed crashes with `__MODULE__` in structs
4. **Protocol System** - Fixed nil handling in protocol concatenation
5. **Stream Fixes** - Better halt handling for Stream.cycle

## Major Features and Improvements

### Erlang/OTP 28 Support

- **Full OTP 28 Compatibility**: Added support for Erlang/OTP 28, ensuring Elixir works with the upcoming OTP release
- **Forward Compatibility**: Validated signatures for forward compatibility (#14235), preparing for future OTP changes

### JSON Enhancements

- **Key Encoding**: Encodes any JSON key to string (closes #14305, #14309), fixing edge cases where non-string keys weren't properly converted

### Language Server and Autocomplete

- **`__MODULE__` Fix**: Fixed autocomplete crash when expanding struct with `__MODULE__` (#14308), preventing crashes during struct expansion in language servers

### Protocol System

- **Nil Concatenation**: Do not discard nil on protocol concat (closes #14311, #14314), fixing protocol consolidation when nil implementations are involved

### Stream Operations

- **Halt Handling**: Do not raise when Stream.cycle is explicitly halted (closes #14307), allowing proper termination of cycled streams

### IEx Improvements

- **Recompile Optimization**: Do not purge on recompile if IEx is not running (closes #14260), improving compilation performance in non-interactive environments
- **Mermaid Graphs**: Use exdoc:loaded to reload mermaid graphs, improving documentation rendering

### Mix and Build System

- **Listener Control**: Support `--no-listeners` in loadpaths, giving developers control over compilation listeners

### Type System

- **Bitstring Typespecs**: Allow `<<_::3*8>>` in typespecs, supporting multiplication in binary size specifications

### Color Handling

- **`--no-color` Fix**: Fixed `--no-color` not setting `:ansi_enabled` to false (#14229), ensuring color is properly disabled

## Bug Fixes

### ExUnit
- **Improper Lists**: Fixed regression when diffing nested improper lists (#14292), restoring proper diff output for complex data structures

### Documentation
- **Process.exit/2**: Added section on differences to Kernel.exit/1 (#14238), clarifying behavior differences
- **String.split/3**: Fixed example in guide and added note in docs (#14223), correcting misleading examples
- **Enum.uniq**: Clarified order on uniq/uniq_by (closes #14304), documenting ordering behavior
- **Deprecation Help**: Improved help on deprecation warning (#14239), making migration guidance clearer
- **Typo Fixes**: Various typo corrections (#14302)
- **CHANGELOG**: Fixed date in CHANGELOG (closes #14303)

## Breaking Changes

No breaking changes were introduced in this release.

## Impact Assessment

This release addresses several important issues while adding OTP 28 support:

**OTP 28 Compatibility**: Prepares Elixir for the next major OTP release, demonstrating proactive compatibility work. Users planning to upgrade to OTP 28 will need this release.

**JSON Fixes**: The key encoding fix ensures robust JSON handling for all map key types, important for applications with diverse data structures.

**Autocomplete Stability**: The `__MODULE__` fix prevents frustrating crashes during development, particularly affecting projects that use `__MODULE__` in struct definitions.

**Protocol System**: The nil concatenation fix prevents subtle bugs in protocol consolidation, important for projects with optional protocol implementations.

**Stream Handling**: The halt fix allows proper control flow with cycled streams, important for reactive programming patterns.

**IEx Performance**: The purge optimization reduces unnecessary work during compilation, speeding up development workflows.

**ExUnit**: The improper list diff fix restores proper test output for projects using advanced list patterns.

**Upgrade Recommendation:** Recommended for all v1.18 users, especially those:
- Planning to use Erlang/OTP 28
- Working with JSON and diverse map key types
- Using language servers with struct expansion
- Working with protocols
- Using Stream.cycle in production code
- Experiencing IEx recompilation slowness

The 43-day gap between releases indicates good stability in the v1.18 line, with this release focusing on forward compatibility and edge case fixes.
