# Changes from v1.7.3 to v1.7.4

## Release Information
- **Release Date**: October 24, 2018
- **Previous Release Date**: August 24, 2018
- **Time Span**: Approximately 2 months
- **Total Commits**: 15 commits (excluding the release commit)

## Summary

Elixir v1.7.4 represents a maintenance release focused on bug fixes, performance improvements, and minor feature enhancements. The release cycle shows steady development with a balanced mix of quality improvements across multiple areas of the language: the standard library, build tools (Mix), and the compiler. The changes reflect attention to edge cases, platform-specific issues (Windows path handling), and infrastructure concerns like archive management and test coverage tracking.

## Major Themes and Areas of Change

### 1. **Bug Fixes and Correctness (Core Focus)**
The majority of commits in this release are focused on fixing bugs and edge cases:
- **Calendar handling**: Fixed a complex issue converting negative ISO days on New Year in leap years (#8145)
- **Test coverage tracking**: Corrected Mix's `--cover` flag to properly reset coverage data between sub-apps in umbrella projects (#8176)
- **Code evaluation**: Fixed `eval_quoted` to properly reset last definition context (#8261)
- **Macro bootstrapping**: Added consideration for cases where Macro may not have been bootstrapped
- **Type specifications**: Fixed typespec issues and improved type annotation consistency (#8207)

### 2. **Feature Additions**
Two notable feature additions provide new capabilities for developers:
- **Mix dependency management**: Added `--no-load-deps` flag to the `deps.loadpaths` task (#8256), allowing more granular control over dependency loading
- **Module attribute metadata**: Enhanced support for using typespec attributes as module attributes (#8327), improving metaprogramming capabilities

### 3. **Developer Experience Improvements**
- **Cross-platform support**: Fixed path expansion in `mix format` to work correctly with Windows-style paths (#8147)
- **Archive management**: Improved archive cleanup by unloading previous versions before building new ones (#8253), preventing version conflicts

### 4. **Performance Optimizations**
- **Calendar optimization**: Avoided unnecessary range creation in `Calendar.ISO.valid_date?/3`, reducing memory allocation and improving performance for date validation operations

## Major Features and Improvements

### 1. Allow Typespec Attributes as Module Attributes (#8327)
This is a significant enhancement for metaprogramming in Elixir. Previously, typespec attributes couldn't be directly used as module attributes, requiring workarounds. This change enables:
- More natural expression of type information in module metadata
- Better integration between typespecs and module attribute reflection
- Changes touch `Kernel.Typespec`, `Module`, and the underlying Erlang module handling code
- Includes comprehensive test coverage with 130+ lines of tests added

**Impact**: Moderately significant - improves the language's metaprogramming capabilities and makes code more expressive for developers working with type information.

### 2. Add --no-load-deps Flag to deps.loadpaths Task (#8256)
This new flag provides developers with finer control over dependency loading:
- Allows tasks to run without fully loading all dependencies
- Useful for scenarios where dependency metadata is needed but not the full dependency artifacts
- Reduces build times for certain operations
- Well-tested with new test cases covering the flag behavior

**Impact**: Moderate - useful for build optimization and special workflows, but likely not impacting most developers directly.

## Bug Fixes

### Critical/Important Bugs:
1. **Calendar Leap Year Bug (#8145)**: Fixed conversion from negative ISO days on New Year in a leap year - this was a data correctness issue that could affect date calculations
2. **Test Coverage in Umbrella Apps (#8176)**: Fixed coverage accumulation across multiple apps in umbrella projects - coverage reports were being incorrectly combined
3. **eval_quoted Context Reset (#8261)**: Ensured `eval_quoted` properly resets the last definition context - prevents state leakage between evaluations

### Minor Bug Fixes:
- Fixed typespec declarations (#8207)
- Fixed compiler consideration for bootstrapped Macro module
- Fixed unused variable warnings (#8158)
- Minor documentation typo in tuple docs (#8162)

### Windows Compatibility:
- **Path Expansion (#8147)**: Fixed `mix format` command to properly expand Windows-style paths (e.g., `path\for\windows.ex`), improving cross-platform compatibility

### Archive Management:
- **Previous Archive Unloading (#8253)**: Archives weren't being properly unloaded before building new versions, which could cause conflicts or build failures

## Performance Improvements

### Calendar.ISO.valid_date?/3 Optimization
- **Change**: Avoid range creation in date validation
- **Benefit**: Reduces memory allocation and improves performance for frequently-called date validation
- **Impact**: Subtle but measurable improvement for applications doing significant date operations

### Inspect.Algebra Type Specification Improvements (#8047)
- Enhanced type specifications in the Inspect.Algebra module to better describe function signatures
- Improves IDE support and type checking tools
