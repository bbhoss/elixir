## Summary

v1.10.4 is a maintenance release that focuses on bug fixes, quality improvements, and compiler optimizations. The release introduces several important fixes to error reporting, task handling, and module loading, along with useful new features for the Mix toolchain. Notably, one feature addition (`--repo` flag for archive.install/escript.install) was initially included but subsequently reverted before the final release, suggesting it required further refinement.

The release demonstrates attention to developer experience through improved error messages, better line number reporting in macros, and enhanced logging capabilities. There are also significant compiler optimizations that reduce unnecessary recompilation in certain scenarios.

---

## Key Themes and Changes

### 1. **Compiler & Build System Optimizations**
The release includes important optimizations to the Elixir compiler, particularly around dependency tracking. The most significant change prevents unnecessary recompilation when using `defdelegate` with dynamic options, which can substantially improve rebuild times in projects that heavily use delegation.

### 2. **Error Reporting & Developer Experience**
Multiple commits focus on improving error messages and diagnostics. This includes proper line number reporting for errors raised inside macros, line numbers for deprecated imports, and better suggestions when Hex packages can't be installed. These improvements make debugging significantly easier for developers.

### 3. **Task and ExUnit Improvements**
Several fixes address Task-related functionality, including proper PID and caller tracking in Task Supervisor reports. ExUnit also gains enhanced exception tracking for linked and trapped exits, helping developers understand error sources better.

### 4. **Module System & Type Handling**
Important fixes ensure proper module loading when required and address edge cases in the type system, such as allowing users to define types named "union" (previously restricted).

### 5. **Runtime Improvements**
Various fixes to how Elixir handles archives, releases, and module loading ensure more reliable runtime behavior, particularly in edge cases involving archived applications.

## Major Features & Improvements

### New Features

1. **`:cd` Option for Mix Commands** (#10029)
   - Adds `:cd` option to `Mix.Shell.cmd/2` function
   - Adds `--cd` flag to `mix cmd` command
   - Allows users to execute shell commands in a different directory without changing the current working directory
   - Useful for scripts that need to operate on external directories

2. **Allow User-Defined "union" Type** (#10055)
   - Removes the restriction preventing users from defining types named "union"
   - Previously, "union" was treated as a reserved type name in the type system
   - Provides more flexibility in type naming

3. **Better Hex Installation Feedback** (#10039)
   - Adds extra suggestions when Hex package installation fails
   - Improves user experience when dependencies cannot be resolved

### Compiler Optimizations

4. **Reduced Compile-Time Dependency for defdelegate** (#10093)
   - Eliminates unnecessary compile-time dependency on delegated modules
   - Only treats module as a compile-time dependency when it's a literal and options are static
   - Significantly improves rebuild times for projects with dynamic delegations
   - Example: With static delegation, only one file recompiles on change; with dynamic delegation, properly handles both scenarios

5. **Improved Error Reporting in Macros** (#10040)
   - Fixes line number reporting when exceptions are raised inside macros
   - Previously, line numbers could be inaccurate or point to the wrong location
   - Essential for debugging complex macro-based code

### Enhanced Diagnostic Information

6. **Line Numbers for Deprecated Imports**
   - Adds line number information to deprecation warnings for imports
   - Makes it easier to locate and update deprecated imports in large codebases

7. **Logger Metadata Improvements for Tasks** (#10111)
   - Includes caller information in translated Logger metadata for Task operations
   - Provides better context in logs for troubleshooting task-related issues
   - Improves observability of asynchronous operations

## Bug Fixes

### Critical Bug Fixes

1. **Force Module Loading When Required**
   - Fixes a fundamental issue with module loading in certain scenarios
   - Ensures modules are properly loaded when explicitly required
   - Minimal change (4 line addition, 3 line removal) but important for runtime correctness

2. **Fix App File Reading from Archives** (#10062)
   - Resolves issue where application metadata couldn't be read from `.ez` archive files
   - Important for users distributing Elixir applications as archives
   - Affects the ability to properly load and introspect archived applications

### Task & ExUnit Fixes

3. **Task PID and Caller in Task Supervisor Reports** (#10025)
   - Fixes incorrect PID and caller information in Task Supervisor reports
   - Ensures that task monitoring and supervision works correctly
   - Critical for production applications relying on task supervision

4. **Exception Blaming for Linked and Trapped Exits in ExUnit**
   - Enhances ExUnit's ability to identify the source of exceptions in linked and trapped exit scenarios
   - Improves test failure diagnostics
   - Helps developers understand which process caused an error

### Pattern Matching & Type System Fixes

5. **Do Not Diff Guards If Pattern Does Not Match** (#10077)
   - Fixes a comparison issue in guard clause evaluation
   - Prevents unnecessary guard diffing when patterns don't match
   - Improves pattern matching correctness

6. **Do Not Raise on Foreign Types**
   - Fixes error handling for types defined outside the current module
   - Prevents spurious errors when working with external type definitions
   - Important for multi-module type systems

### Encoding & Configuration

7. **Support Proper Encoding in Releases Config** (#10012)
   - Fixes encoding handling in release configuration files
   - Ensures special characters and non-ASCII content are properly handled in release metadata
   - Improves internationalization support

## Reverted Changes

### Reverted Feature (Before Final Release)

**Add `--repo` to archive.install and escript.install** (#10121)
- **Status**: Added in commit e9ea9dea7f, then reverted in commit 12f93df04f
- **Timeline**: Added June 22, 2020; reverted July 1, 2020
- **Reason**: The feature was reverted shortly before the final release, suggesting it required further refinement or introduced unintended side effects
- **Impact**: Users cannot specify a custom repository when installing archives or escripts in this release

This reversion indicates careful release management, where the team identified an issue before shipping and decided it was better to remove the feature than to release it in an incomplete state.
